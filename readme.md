# ⚙️ Dashboard Admin - ghancstm 3D Print

Responsi Pemrograman Fullstack yaitu Dashboard Admin Manajemen Pesanan untuk layanan cetak 3D Ghancstm. Responsi ini menggunakan (React JS (Vite)) dengan menerapkan fitur CRUD, (Bootstrap) untuk styling, serta (jQuery) untuk efek animasi.

## Fitur Utama
1. Create: Menambahkan antrean pesanan baru (Nama, Model, Kategori, Status).
2. Read: Menampilkan daftar antrean dengan badge warna dinamis.
3. Update: Mengedit detail dan mengubah status pesanan yang sedang berjalan.
4. Delete: Menghapus pesanan yang sudah selesai atau dibatalkan (dengan animasi jQuery).
5. Search: Filter pencarian real-time berdasarkan nama pelanggan atau nama model.
